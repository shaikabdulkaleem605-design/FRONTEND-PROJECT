# MoneyFlow — Personal Finance Dashboard

A responsive finance dashboard inspired by the reference screenshot, built with HTML, CSS, and vanilla JavaScript.

## Files
- `index.html` — dashboard structure
- `style.css` — responsive styling, dark theme, layout
- `script.js` — transactions, totals, localStorage, filtering, charts

## Run
Open `index.html` in a browser. Internet is needed to load Chart.js and Google Fonts from their CDNs. If the chart CDN is unavailable, the transaction manager and totals still work.

## Features
- Income, expense, and balance summary cards
- Monthly income vs expense line chart
- Expense category doughnut chart
- Add and delete transactions
- Search transactions by name/category
- Filter by income or expense
- Persistent data using localStorage
- Responsive layout and dark-mode toggle
- Sample data for demonstration
